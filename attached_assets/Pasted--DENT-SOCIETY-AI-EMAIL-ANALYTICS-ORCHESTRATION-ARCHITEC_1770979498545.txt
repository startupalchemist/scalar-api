# OBJECTIVE

Build the AI agent system, newsletter system, and analytics insights layer using:

PRIMARY:
• Replit Native OpenAI Connector
• Replit Native Resend Connector (email)
• Replit native DB / storage (if used)

SECONDARY (Fallback for Migration):
• Direct OpenAI API via API key
• Direct Resend API via API key
• Direct SMTP or email provider
• External Postgres connection
• External analytics provider

# CORE PRINCIPLE

Implement a PROVIDER ABSTRACTION LAYER.

Never call OpenAI or Resend directly from business logic.

All external services must route through:

/lib/providers/aiProvider.js
/lib/providers/emailProvider.js
/lib/providers/analyticsProvider.js

This allows swapping connectors without touching application logic.

# AI PROVIDER ABSTRACTION

File:
/lib/providers/aiProvider.js

Structure:

export async function generateAIResponse(prompt, options) {

  if (process.env.AI_PROVIDER === "replit") {
    // Use Replit native connector
    return await replitOpenAI.chat.completions.create({
      model: "gpt-4o",
      messages: [{ role: "user", content: prompt }],
      ...options
    });
  }

  if (process.env.AI_PROVIDER === "direct") {
    return await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.OPENAI_API_KEY}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        model: "gpt-4o",
        messages: [{ role: "user", content: prompt }],
        ...options
      })
    }).then(res => res.json());
  }

}

All AI agents must use this function.

Never call OpenAI directly elsewhere.

# EMAIL PROVIDER ABSTRACTION

File:
/lib/providers/emailProvider.js

export async function sendEmail(payload) {

  if (process.env.EMAIL_PROVIDER === "replit") {
    return await replitResend.emails.send(payload);
  }

  if (process.env.EMAIL_PROVIDER === "direct") {
    return await fetch("https://api.resend.com/emails", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.RESEND_API_KEY}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify(payload)
    }).then(res => res.json());
  }

}

Newsletter publishing and transactional emails must call this function.
