# 4️⃣ BACKEND – OPERATIONAL FLOW (SYSTEM LOGIC)

This flow is NOT displayed fully to customers but must exist in CRM + AI knowledge base.

---

SALE  
↓  
CLAIM INITIATED  
↓  
REPAIR AUTHORIZATION SIGNED  
↓  
LOANER ASSIGNED (IF APPLICABLE)  
↓  
VEHICLE IN SHOP  
↓  
SCOPED  
↓  
ESTIMATE CREATED  
↓  
FIRST LOOK (Insurance Review)  

IF APPROVED → Continue Forward  

IF INSUFFICIENT →  
SUPPLEMENT SUBMITTED  
↓  
RETURN TO APPROVAL  

Once final approval received →  

↓  
R&I (Removal & Install – Pre-Repair)  
↓  
PDR  
↓  
QC #1  
↓  
R&I REINSTALL  
↓  
QC #2  
↓  
DETAIL  
↓  
DELIVERED  
↓  
CLOSED  

---

# IMPORTANT SYSTEM RULE

SUPPLEMENT is not a step before approval.

It is a branch triggered only if initial approval is insufficient.

Flow always returns to APPROVAL before continuing.

# 7️⃣ 48-HOUR GUARANTEE TRIGGER LOGIC

The 48-hour completion clock begins ONLY when:

• Insurance approval is finalized  
• Vehicle is in shop possession  
• Required parts (if any) are available  

It does NOT begin at:

Sale  
Drop-off  
Estimate  
First Look  

This logic must be reflected in:

• FAQ copy  
• AI assistant responses  
• Admin dashboard timer logic
